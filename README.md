# Kenyan-Job-market-analytics-
A data analytics project analyzing job market trends, skill demand, experience requirements, and hiring patterns in Kenya using Python, SQL, and Power BI.
# Kenya Job Market Analytics

## Overview

To Find a job in Kenya can be challenging, especially for graduates and early-career professionals who are unsure which skills employers are looking for. This project aims to analyze job postings from the Kenyan market to identify hiring trends, in-demand skills, experience requirements, and geographic patterns.

The goal is to use data analytics techniques to transform raw job posting data into meaningful insights that can help job seekers make informed career decisions.

## Objectives

* Identify the most frequently requested technical skills.
* Analyze experience requirements across different job roles.
* Examine hiring trends in different locations within Kenya.
* Explore demand for technologies such as Python, SQL, Power BI, Java, and cloud platforms.
* Present findings through visualizations and dashboards.

## Project Structure

* **data/** – Raw and cleaned datasets.
* **notebooks/** – Data exploration and analysis notebooks.
* **src/** – Python scripts used for data processing.
* **sql/** – Database scripts and queries.
* **dashboard/** – Power BI dashboard files.
* **visuals/** – Charts and exported visualizations.
* **docs/** – Project planning and supporting documentation.

## Methodology

The project follows a data analytics workflow:

1. Data collection
2. Data cleaning and preparation
3. Exploratory data analysis
4. Skill extraction and trend analysis
5. Dashboard development
6. generation and reporting of insights

## Expected Outcomes

 To identify the skills and qualifications most demanded by employers in Kenya and present the findings through an interactive dashboard and supporting visualizations.
